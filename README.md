# gigagist

A practical collection of cybersecurity notes, labs, workflows, and scripts built throughout my journey into cybersecurity.

The repository focuses on hands-on security learning across:

- Offensive Security — Pentesting, Web Exploitation, Active Directory
- Cloud Security — AWS, IAM, Storage, and Cloud Misconfigurations
- Security Operations — SIEM, Threat Hunting, Detection Engineering, DFIR
- Governance, Risk & Compliance — NIST, ISO 27001, CIS Controls

## 📂 Contents

- `notes/` → Learning notes, methodologies, and security concepts
- `scripts/` → Reconnaissance, enumeration, and automation scripts
- `CTF/` → CTF write-ups and practical security investigations
- `resources.md` → Tools, references, and useful learning resources

## 🧑‍💻 Current Focus

- Hack The Box CPTS & CDSA preparation
- Advanced Web Exploitation — SQLi, XSS, SSRF, Command Injection
- Cloud Security — AWS, IAM, S3, EC2, and cloud misconfigurations
- SIEM Detection Engineering & Log Correlation
- Digital Forensics & Incident Response
- NIST & ISO 27001 practical mapping

## 🎯 Goal

Build practical skills across offensive security, cloud security, and defensive security while documenting the learning process through hands-on labs, CTFs, and security research.
